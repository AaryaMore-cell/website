## 🏛️ Overview

Aethelgard presents an institutional B2B security interface designed around psychological bureaucracy and deceptive micro-interactions:

- **Deceptive Design System**: Ultra-modern dark theme (`#0f172a`), precision blue accents (`#3b82f6`), glassmorphism, and subtle glow shadows.
- **The Infinite Onboarding Loop**: A verification wizard where the target step count expands dynamically (`Step 1 of 3` ➔ `Step 2 of 5` ➔ `Step 3 of 9` ➔ `Step 4 of 14` ➔ `Step 5 of 22`).
- **Latitude-Sorted Tax Enclaves**: Country selection dropdown arranged strictly by geographic coordinate latitude (North Pole to South Pole) instead of alphabetical order.
- **Auto-Resetting Legal Buffer**: A Terms & Conditions agreement box that automatically and smoothly resets its scroll position to the top every 6 seconds, revoking consent if not committed in time.
- **Shifting Passkey Constraint Matrix**: Real-time mutually antagonistic password rules requiring primes, ambient Geneva temperatures, enterprise emojis, exact digit sums (37), and regional airport codes.
- **Evasive Button Swap**: The primary "Continue Pipeline" button swaps positions and click-handlers with "Cancel Verification" after a 150ms hover delay.
- **Artificial Consensus Queue**: A zero-knowledge progress bar that jumps to 99% and freezes for 8 seconds before returning non-descriptive system error codes (`ERR_STATIONARY_STATE`).

## 🚀 Running Locally

Open `index.html` directly in any modern web browser (Google Chrome, Microsoft Edge, Firefox, Brave):

```bash
# Direct browser launch
start index.html
```

Or serve with any static web server:

```bash
# Python
python -m http.server 8080

# Node.js
npx serve .
```
